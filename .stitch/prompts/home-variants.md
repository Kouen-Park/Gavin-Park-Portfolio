# Google Stitch home explorations

Use `DESIGN.md` as the project-level design system. Generate desktop-first web screens with real content and no invented claims.

## Shared purpose

A software developer portfolio for recruiters. The visitor must understand Gavin Park's positioning, three selected projects, proof of engineering decisions, and the GitHub contact route within one minute.

## Variant A — Editorial rail

Create a home page where a continuous evidence rail begins beside the hero thesis and continues into three large alternating project stories. Each project shows one authentic screenshot, status, role, technologies, one decision, and one verification fact. Finish with a six-step working method, one coursework archive row, and a restrained GitHub invitation.

## Variant B — Split case study

Create a home page with a persistent left identity column and a scrolling right case-study column. Keep the project media dominant, and connect the selected work with a thin evidence trace that labels problem, implementation, and verification. Collapse to a single reading column on mobile.

## Variant C — Gallery forward

Create a home page that opens with one large BirdieBuddy product capture, then layers the positioning statement and evidence labels around it. Follow with full-width game and knowledge-system stories, each using different editorial image proportions while preserving the same evidence structure.

## Evaluation rubric

Score each variant for recruiter scan speed, factual clarity, mobile reading order, keyboard navigation, authentic project emphasis, and whether the Evidence Rail remains memorable without overpowering the content.
